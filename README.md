# Mini browser games (HTML + JavaScript)

A small collection of single-file games made while learning web development by Darshankumar Savsani (Diploma CE student, Rajkot).

## Games

- Math Quiz, Typing Speed Test, Memory Card Flip
- Breakout, Dodger, Catch the Falling Object
- Snake (classic Nokia style), Maze Escape

## Play

Download the repo and open any `.html` file in a browser. Each game is one file with no libraries.

## Tech stack

HTML5, CSS3, vanilla JavaScript.
